A kernel-weighted lognormal forecaster for GTA VI's launch-day Twitch viewers: it reads the release day's first-hour print and the comparables' launch curves, then forecasts hours 2–24 as five quantiles an hour. Leave-one-out over 29 midnight-local-like launches: mean pinball loss 0.264, vs 0.360 for the house persistence baseline.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
